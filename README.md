# blue whale 桌宠（AstrBot 插件）

桌面上的 Live2D 桌宠「大肥鱼」，和 AstrBot 里的角色当面说话。你对桌宠打字或用麦克风说话，由 AstrBot 回答——你在 AstrBot 里设的人格、对话记录、其他插件（记忆、陪伴类插件等）都会生效；回复带着表情动作回到桌宠，由桌宠念出来。

> 只支持 **Windows**。需要 AstrBot **4.29 及以上**，并且已经配好一个能聊天的模型。

## 安装
1. AstrBot 后台 →「插件」→ 插件市场搜索 `blue whale`（或 `astrbot_plugin_bluewhale`），点安装。
2. **第一次会自动下载桌宠程序**（约 485MB，只下一次）：右下角会弹出「正在下载桌宠」的通知，下好、解压完桌宠会自己出来。
   - 先从 Gitee 下（国内不用梯子），不行再从 GitHub 下；下完会核对文件指纹，下坏了不会装上。
   - 下载失败（比如断网）：重启 AstrBot 会接着下，已下好的部分不用重下。
3. 插件会自动在 AstrBot 的「平台」里加上「**blue whale 桌宠**」，不用手动添加。

以后 AstrBot 一打开，桌宠就出来；AstrBot 关掉，桌宠一起关。

> 杀毒软件（360 等）可能误删桌宠里的文件，导致桌宠没有托盘图标、角色被关在小框里。可以把 AstrBot 数据目录下的 `plugin_data\astrbot_plugin_bluewhale` 加入信任。

## 用法
- **拖动**：按住大肥拖动（只能在当前屏幕里拖）。
- **说话**：右键桌宠，打开聊天或麦克风。语音由桌宠自己听写成文字，再交给 AstrBot。
- **切换聊天**：右键桌宠 →「切换聊天」，列出 AstrBot 里桌宠的对话，也可以「新建」一个。
- **跳舞**：右键「动作 ▸ 跳舞」，或对她说「跳个舞」。
- **回到屏幕中心**：右键托盘小图标点「回到屏幕中心」（拖丢了时用）。
- **托盘「显示/隐藏桌宠」**：点一下隐藏，再点一下显示。

## 表情动作规则
和桌宠说话时，插件会自动把「桌宠规则」加进系统提示词（只对桌宠生效，QQ 等其他平台不受影响），告诉角色怎么写表情动作、换装、跳舞的标记。**不要**把这些写进人格。

想改规则：把插件里的 `桌宠规则.md` 复制到 AstrBot 数据目录的 `plugin_data\astrbot_plugin_bluewhale\桌宠规则.md` 再改，下一句话就生效，插件更新也不会冲掉。

## 设置（插件 →「插件配置」）
| 设置 | 默认 | 说明 |
|---|---|---|
| 桌宠程序位置 | 自动 | 一般不用填 |
| 没有桌宠时自动下载 | 开 | 约 485MB，只下一次 |
| AstrBot 启动时打开桌宠 / 关掉时一起关 | 开 / 开 | |
| 和桌宠说话时附上桌宠规则 | 开 | |
| 分段回复一段一个气泡 | 开 | 关掉 = 所有分段合成一个气泡 |
| 等角色回复最多几秒 | 180 | |
| 说话动作、换装用动作 | | 一般不用改 |

桌宠连接的端口在「平台 → blue whale 桌宠」里，默认 18100。

## 要知道的
- **和 DSH 版 blue whale 不能同时开**：两边都用 18100、18101 端口。同一台电脑装过 DSH 版的话，本插件会直接用那边已有的桌宠，不用再下载。
- **分段回复**：AstrBot 开了分段回复时，第一段马上念，后面的一段一段冒出来（桌宠说完话 5 秒后开始取，之后每 2 秒取一次）。
- **后续消息**：角色说完后补的话（提醒、其他插件主动发给桌宠的话）会存起来，桌宠说完话后的 1 分钟内会来取。平时桌宠不会主动开口。
- **国内用麦克风**：桌宠判断「有没有人在说话」的语音检测模型原本要从 huggingface.co 下载，国内连不上。插件自带这个模型，在本机 18101 端口提供，并在打开桌宠前把桌宠里的下载地址改成本机，所以要让 AstrBot 来打开桌宠（不要单独打开 airi.exe）。
- **打开桌宠前的小修补**：插件会对桌宠程序做几处「同样长度原位替换」（语音检测地址、屏幕边缘和四个角不抢鼠标、托盘显示/隐藏）。
- **文件在哪**：桌宠在 AstrBot 数据目录的 `plugin_data\astrbot_plugin_bluewhale\pet-版本号\`。卸载插件后想彻底删掉，把这个文件夹删了。
